# KRATOR Multilingual Localization

## Languages

Support English source content plus Spanish, Portuguese for Brazil, French, Russian, and Arabic. Treat English as the approved source unless the user supplies another authoritative source.

## Workflow

1. Confirm that the source page and product facts are approved and current.
2. Build a page-specific terminology list for product names, carrier data, mounting dimensions, hydraulics, applications, and quote fields.
3. Translate for professional local usage and search intent, not sentence-by-sentence literal similarity.
4. Preserve numbers, units, model names, URLs, form behavior, and factual qualifiers.
5. Localize title, description, headings, ALT text, visible FAQs, CTA labels, and schema text together.
6. Preserve canonical and hreflang relationships and the current multilingual `noindex` policy unless explicitly changed.
7. For Arabic, set correct language and RTL direction, then verify mixed Latin model names and numbers visually.
8. Run untranslated-string, broken-link, metadata, overflow, and build checks.

Do not create thin locale pages, mix languages within core content, translate brand names, or invent region-specific availability and compliance claims.
