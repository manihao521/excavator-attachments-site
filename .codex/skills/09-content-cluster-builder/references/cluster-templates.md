# KRATOR Cluster Templates

Use the common A-J output in `SKILL.md`. Complete only the template relevant to the request.

## Buying Guide Cluster

**Pillar role:** Complete selection guide for `[product family]`.

| Field | Required detail |
| --- | --- |
| Buyer | Contractor, dealer, distributor, rental company, or procurement buyer |
| Decision | Product type, carrier fit, application, hydraulics, mounting, order requirements |
| Pillar URL | Existing or proposed canonical route |
| Support topics | Sizing, subtype selection, measurement, specifications, applications, quote checklist |
| Product links | Category and relevant subtype pages |
| Evidence | Verified tables, machine data, images, factory or inspection proof |
| CTA | Send excavator model and working condition, or request quote |

Reject support topics that repeat the pillar's primary selection intent.

## Comparison Cluster

**Pillar role:** Help a buyer choose between two products, configurations, or methods.

For each comparison page record:

- Compared entities and canonical product URLs
- Buyer situation and decision trigger
- Neutral comparison dimensions
- Best-fit applications and limitations
- Machine and hydraulic matching variables
- Evidence needed for every performance claim
- Related product and buying-guide links
- CTA requesting the data needed to decide

Do not manufacture a winner. State when each option is appropriate.

## Maintenance Cluster

**Pillar role:** Prevent downtime and help buyers maintain `[product family]` safely.

Map support pages by task or failure mode:

- Daily inspection
- Lubrication and wear parts
- Hydraulic hose, flow, and pressure checks
- Mounting and pin wear
- Troubleshooting symptoms
- Storage and transport
- Spare-parts identification

Require verified service instructions. Do not invent intervals, tolerances, safety procedures, or warranty terms.

## OEM Cluster

**Pillar role:** Explain verified OEM, ODM, private-label, bracket, and batch-order support.

Include:

- Buyer type and order scenario
- Existing Custom Service, About, Factory, product, and Contact URLs
- Customization inputs required from the buyer
- Engineering confirmation points
- Inspection, documentation, packing, and approval evidence available
- Private-label or distributor claims requiring confirmation
- CTA for drawings, machine data, quantity, branding, and destination

Do not imply ownership of facilities, certifications, production capacity, or exclusive customers without proof.

## Country Market Cluster

**Pillar role:** Serve a distinct regional buyer need, not a search doorway.

Require before recommending a URL:

- Country and professional language
- Verified product demand or application pattern
- Buyer roles and procurement workflow
- Shipping, port, climate, machine-fleet, or compliance evidence
- Local terminology and measurement conventions
- A distinct value beyond replacing the country name
- Localized product, guide, About, Factory, and Contact link plan

If evidence is insufficient, return a research brief instead of a landing-page recommendation.

## Case Study Cluster

**Pillar role:** Organize real project evidence by product, application, buyer problem, or region.

Required record:

- Approval status and confidentiality limits
- Machine brand/model and carrier data
- Attachment and configuration
- Jobsite material and objective
- Selection constraints
- Installation or matching process
- Verified result and how it was measured
- Real images, documents, dates, and reviewer
- Related product, application, Factory, and Contact links

Use anonymized language only when approved. Never invent a customer, quote, result, location, or performance number.
