Erros comuns When Buying Box Type Rompedor hidráulico

  • Choosing only by excavator tonnage
  • Ignoring oil flow and pressure
  • Not confirming pin diameter and arm width
  • Using a light breaker for hard rock
  • Forgetting seal kits, bushings and chisels
